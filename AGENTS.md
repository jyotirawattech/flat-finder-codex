# Flat Finder for Codex

This is the shareable product, not a user's housing database. Keep real profiles,
phone numbers, messages, workplace coordinates, credentials and screenshots out of
this tree. Use an external private workspace for real searches.

The installable skill is `flat-finder/`. Run `python3 -m unittest discover -s tests`
and `python3 scripts/release.py --check` before a release. The viewer is a local
companion to the Codex workflow, not an authenticated Facebook or WhatsApp API.
Never infer a live send, current vacancy or walkability from an imported ad.

Do not publish, create accounts or change schedules as part of local builds.
Distribution and launch drafts must describe demonstrated behavior and limitations.
