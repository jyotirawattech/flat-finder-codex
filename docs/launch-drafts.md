## LinkedIn

I built Flat Finder for Codex because a rental shortlist needs more than a price
and a nearby location label.

It keeps the source post, rent plus maintenance, deposit, move-in availability and
commute evidence together. A 1 km radius stays separate from a checked walking
route. Missing details stay visible, and already-sent or closed enquiries don't
become fresh leads when a listing appears again.

You install it as a Codex skill, save your own search profile privately, and use
Codex's available web/browser tools to research. The local map helps compare what
has actually been checked. It doesn't promise a live feed or send messages itself.

The demo uses made-up listings. The skill and local tools are available to inspect
and adapt for your own search.

https://flat-finder-codex.pages.dev
https://github.com/jyotirawattech/flat-finder-codex

## Developer-community post

Title: I built a rental-search skill for Codex with a local map and an evidence trail

I wanted the shortlist to explain why a place might fit and what was still unknown.
This skill saves requirements, research evidence and contact state in local JSON,
then shows a map, property details, source links and CSV/Markdown exports.

The Python helpers use the standard library. The viewer uses vanilla JS and
Leaflet. Codex performs the actual source inspection through tools available in
the user's session. There is no bundled account access, scraper or automatic send.

I'm sharing the implementation and a synthetic demo. Feedback on the evidence
model, repeated-listing handling and local workflow would be useful.

## Release description

Flat Finder for Codex v1.0.0 includes an installable rental-research skill,
private local workspace tools, a responsive map/shortlist viewer and a synthetic
static demo. It separates advertised prices/dates, current provider confirmation,
geographic radius, walking evidence and contact delivery states.

Python 3.10+ on macOS/Linux. No pip packages or API key required for local tools.
Codex web/browser access and live source research remain external prerequisites.

Artifacts: source bundle, skill-only bundle, static demo and SHA-256 sums.
